# EV08 Gestión de colecciones y servicios

Esta entrega extiende el Sistema de Biblioteca existente. Conserva los modelos y menús previos, y agrega una capa `Services/` que administra listas de libros, usuarios y préstamos.

## Ejecución

Desde la carpeta del proyecto, ejecuta `dotnet run` y elige la opción **6. Demostración EV08 (servicios)**. La opción 7 conserva la salida habitual del programa.

La demostración muestra:

- La diferencia entre un array de tamaño fijo y `List<T>` dinámica.
- Búsquedas por ISBN, documento e ID de préstamo.
- Ordenamientos de libros, usuarios y préstamos.
- KPIs de disponibilidad de libros, estado de usuarios y préstamos, y promedio de días.
- Registro de una devolución y liberación del libro.

Las clases de servicio mantienen la lista interna y devuelven una copia al solicitar todos los registros.
